# Contributions

Phase 6 implements accepted contribution schedules, immutable obligation terms, authoritative balance/status derivation, verified receipt allocations, reviewed fee rules, extensions/waivers, private deadline jobs, in-app reminder scheduling and collection/round dashboards. Existing Phase 4 financial records remain authoritative for principal. See [Phase 6 notes](../../../PHASE-6.md) for workflow, local-only migration, access rules, semantics and verification. Payment initiation and reward execution remain outside this phase.
