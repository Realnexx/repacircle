# Rewards

Phase 5 implements a database-driven catalog, six validated reward types, immutable versions and mixed components, reusable templates/categories, custom attribute editing, private galleries/files, exact pricing, and group/round assignments. Existing REPA funding and agreement flows consume pinned versions. See [Phase 5 notes](../../../PHASE-5.md) for rollout, limits and verification. No payment or fulfillment execution is implemented.
